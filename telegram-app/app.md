# Telegram Mini App (tgui) — что рендерит фронтенд

Спецификация интерфейса мини-приложения. Описывает, **что пользователь видит на
каждом экране**: блоки, поля, подписи, кнопки, справочные списки.

Документ описывает только отображение. Логика, эндпоинты, типы, модели,
состояния загрузки/ошибки/пустоты сюда не входят.

**Как читать.** Раздел «Экраны» — по маршрутам сверху вниз. Раздел «Окна» —
всплывающие окна, каждое описано тем, что оно показывает. Раздел «Справочники»
— закрытые списки значений, которые UI показывает как подписи.

---

## 1. Каркас

Оболочка приложения постоянна и одинакова для всех экранов:

- **Верхняя панель** — заголовок текущего раздела + кнопка «Назад» (кроме
  корня) + кнопка настроек в профиле.
- **Нижний таб-бар**, 5 вкладок:

  | Вкладка     | Подпись     | Экран            |
  | ----------- | ----------- | ---------------- |
  | Главная     | Главная     | `/`              |
  | Поездки     | Поездки     | `/bookings`      |
  | Поиск       | Поиск       | `/trips`         |
  | Уведомления | Уведомления | `/notifications` |
  | Профиль     | Профиль     | `/profile`       |

  У вкладки «Уведомления» есть числовой бейдж непрочитанных.

- **Экран** — вертикальная колонка секций. Каждая секция имеет заголовок.
- **Типографика**: крупные заголовки (`Text weight=2`), подписи (`Caption`),
  основной текст (`Text`).
- **Палитра** — только токены темы Telegram UI, своих цветов нет.

## 2. Экраны

### 2.1 Главная — `/`

Сверху вниз:

1. **Карточка профиля** — строка `Cell` с аватаром 48px слева, именем и
   подписью «поездок: N», справа пилюля рейтинга. Вся строка нажимаема.

2. **Сводка** — три плитки в ряд (`InlineButtons`, серый фон), у каждой иконка
   и числовой бейдж:
   - «Поездки» — иконка автомобиля, счётчик своих активных поездок.
   - «Брони» / «Ожидают» — иконка билета. Подпись меняется: если есть брони в
     ожидании — «Ожидают», иначе «Брони»; показывается число ожидающих,
     иначе подтверждённых.
   - «Заявки» — иконка входящих, число заявок пассажиров к своим поездкам.

3. **Баннер ближайшей поездки** (если есть): маршрут «Откуда → Куда», строка
   «когда · цена · место», подпись «свободно N».

4. **Секция «Поиск попутных поездок»** — два поля с подписями:
   - «Откуда» — плейсхолдер «Город или село отправления»
   - «Куда» — плейсхолдер «Город или село назначения»

5. **Секция «Кто ищет попутку»** — список строк `Cell`. Строка: маршрут
   «Откуда → Куда», вторая строка «N человек · N мест · дата, время».

6. **Секция «Едете на машине?»** — кнопка с иконкой плюса в круге:
   **«Создать поездку»**.

7. **Секция «Нужна попутка?»** — кнопка с иконкой людей:
   **«Создать запрос»**.

### 2.2 Поиск — `/trips`

1. **Секция «Поиск попутных поездок»**:
   - поле «Откуда» (плейсхолдер «Город или село отправления»)
   - кнопка «Поменять направление» между полями (иконка стрелки)
   - поле «Куда» (плейсхолдер «Город или село назначения»)
   - поле «Цена не выше»
   - ряд чипов тегов поездки
   - кнопка сброса фильтров

2. **Строка счётчика** — «Найдено поездок: N» и подпись «Цены без комиссии».

3. **Лента поездок**, сгруппированная по дате, над каждой группой — заголовок
   с датой. Элементы ленты — карточки поездки:

   **Карточка поездки**:
   - верхняя строка: дата и время отправления; рядом статус поездки
   - маршрут: «Откуда → Куда»
   - карточка водителя: аватар, имя, пилюля рейтинга, число отзывов
   - автомобиль: «Модель · Цвет»
   - ряд тегов (чипы)
   - «В пути ~ 2 ч 30 мин» и расстояние «180 км»
   - цена «500 ₽»

   Вся карточка нажимается целиком и открывает поездку. Видимой кнопки на ней
   нет — «Открыть поездку» существует только как подпись для скринридера.

4. Внизу ленты — кнопка догрузки следующих карточек.

### 2.3 Поездка (карточка) — `/trips/:tripId`

Один экран, три варианта содержимого: пассажир, водитель, иное.

**Шапка поездки:**

- дата отправления, статус поездки
- ряд плиток: длительность в пути, расстояние
- **маршрут по вертикали** (таймлайн): для каждой точки — время и город, ниже
  адрес. Точек две: отправление и прибытие.

**Карточка водителя:**

- аватар, имя, пилюля рейтинга, «(N отзывов)»
- две круглые кнопки-иконки: «Поделиться поездкой», «Позвонить водителю»
- кнопка «Поделиться поездкой с попутчиком в Telegram»

**Автомобиль:** «Модель · Цвет», ниже госномер либо подпись
«Госномер после брони».

**Теги:** ряд чипов (теги поездки).

**Комментарий водителя** — блок с подписью «Комментарий водителя:».

**Панель пассажира:**

- «Выбор места» — ряд кнопок по номерам мест. Занятое место подписано
  «(зан.)» и неактивно, выбранное помечено.
- поле «Комментарий водителю», плейсхолдер
  «Например: буду с небольшим чемоданом, подойду к 9:25»
- «Цена за место» и «500 ₽», подпись «Оплата водителю при посадке»
- основная кнопка **«Забронировать место №1 · 500 ₽»** (без выбранного места — «Забронировать место»)
- кнопка «Отменить бронирование» с подтверждением:
  «Заявка будет отменена, а место снова станет доступно.»

**Панель водителя** (заголовок «Управление поездкой»):

- кнопка «Заявки пассажиров (N)»
- кнопка «Редактировать поездку»
- «Завершить поездку» с подтверждением: «Поездка будет перенесена в архив, а
  пассажиры смогут оставить отзывы.»
- «Отменить поездку» с подтверждением: «Поездка станет недоступна, а пассажиры
  получат уведомление об отмене.»
- подпись под завершением: «Завершение станет доступно после времени
  отправления.»
- подпись под отменой, когда поездка уехала: «Отмена недоступна после
  отправления — поездку можно завершить.»

### 2.4 Создание поездки — `/trips/my/new`

Секции формы:

1. **«Нужен автомобиль»** — вход в форму автомобиля, когда его нет.
2. **«Маршрут»**:
   - «Город отправления» — подпись поля «Откуда едем»
   - кнопка «Поменять направление»
   - «Город назначения» — подпись поля «Куда едем»
   - «Адрес отправления» — подпись поля «Точка встречи»
   - «Адрес назначения» — подпись поля «Точка прибытия»
3. **«Поездка»**:
   - «Дата и время» (дата и время отправления)
   - «Цена, ₽»
   - «Места» (1–3)
   - «Расстояние, км»
   - «В пути, часов» (длительность)
4. **«Условия поездки»**:
   - «Комментарий», плейсхолдер
     «Например: едем спокойно, салон чистый, багажник свободен»
   - чипы тегов поездки
5. **«Опции поездки»** — два переключателя:
   - «Завершать поездку сразу» — подпись «Завершать сразу после поездки»
   - «Предлагать поездку подходящим попутчикам» — подпись «Предлагать
     подходящим»

Кнопка публикации. После публикации — текст статуса вида
«Вологда → Тула появилась в поиске».

### 2.5 Поездки (мои) — `/bookings`

Экран состоит из двух частей: **список** и **переключатель вкладок**.

**Переключатель вкладок:**

- «Все»
- «Водитель» — свои поездки как водитель
- ««Пассажир» — свои поездки как пассажир

**Поле поиска** над списком: плейсхолдер «Поиск по откуда и куда».

**Карточка своей поездки (водитель)**:

- маршрут, дата-время, статус
- «Заявки: N» и «Забронировано: N/M»
- «Свободно: N»
- «Пассажиры: N»
- цена
- кнопка «Отменить поездку»

**Карточка своей поездки (пассажир)**:

- маршрут, дата-время, статус
- водитель, автомобиль
- кнопка «Отменить бронь» с подтверждением: «Заявка будет отменена, а место
  снова станет доступно.»
- кнопка «Поделиться поездкой»

Внизу — кнопка догрузки.

### 2.6 История поездок — `/profile/history`

Список строк `Cell`. Строка:

- иконка (автомобиль — своя поездка, человек — поездка как пассажира)
- подпись: «дата, время · статус»
- справа: цена «500 ₽» либо **красный бейдж «1»**, если поездка ждёт отзыва
- вспомогательное имя строки для скринридера: «Поездка Откуда — Куда,
  статус» либо «… , оставьте отзыв»

### 2.7 История запросов — `/profile/ride-requests`

1. **Секция «Нужен попутчик»** — форма нового запроса (см. окно «Новый запрос»).
2. **Секция «Мои заявки»** — список карточек своих заявок на попутку.

**Карточка заявки:**

- маршрут «Откуда → Куда»
- подпись-статус: Активен / На паузе / Выполнен / Истёк / Отменён
- «не раньше — не позже · N мест»
- кнопки по состоянию:
  - «Поставить на паузу» (Активен)
  - «Возобновить» (На паузе)
  - «Редактировать» — открывает inline-форму прямо в карточке
  - «Отменить запрос» с подтверждением: «Запрос будет снят с публикации.»
- подпись у просроченной заявки: «Срок действия истёк — создайте новый запрос.»

**Inline-форма редактирования** (внутри карточки) — поля:
«Не раньше», «Не позже», «Действует до», «Места», кнопки «Сохранить» и
«Отмена».

Внизу списка — кнопка догрузки.

### 2.8 Профиль — `/profile`

| Секция                         | Содержимое                                                                                                                                        |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| Шапка                          | Аватар 96px, имя, телефон, «поездок: N», пилюля рейтинга, текст «N отзывов»                                                                       |
| «Мои поездки»                  | Строка «История поездок» + подпись «Завершённые и отменённые поездки»                                                                             |
| (без заголовка)                | Строка «История запросов» + подпись «Мои заявки на попутку»                                                                                       |
| (без заголовка)                | Строка «Отзывы» + подпись «Мои отзывы и отзывы обо мне · N»                                                                                       |
| «Мой автомобиль (для поездок)» | Строка с автомобилем: «Модель · Цвет», госномер; при отсутствии — «Автомобиль не добавлен»                                                        |
| «Внешний вид»                  | Переключатель «Тёмная тема», подпись «Включена тёмная тема (как в Telegram)» либо «Включена светлая тема (как в Telegram)»                        |
| «Уведомления и звуки»          | Строка «Уведомления» + подпись «Брони, статусы поездок, ответы поддержки»; строка «Звуковые эффекты» + подпись «Звуковые сигналы и вибрация»      |
| «Сервис и помощь»              | «Служба поддержки» + подпись «Вопросы и обращения — ответим в течение нескольких минут»; «Жалобы» + подпись «Сообщить о проблеме с пользователем» |
| «Опасная зона»                 | Строка «Удалить профиль» + подпись «Аккаунт будет анонимизирован.»                                                                                |

### 2.9 Отзывы — `/reviews`

**Переключатель вкладок:** «Мои» · «Новая» · «Обо мне».

**Вкладка «Новая»** — форма отзыва:

- поле «Поездка» — выбор поездки
- поле «Кому оставить отзыв» — выбор адресата (для своей поездки — пассажира)
- «Оценка» — ряд из 5 звёзд, подпись «Оценка N из 5»
- «Комментарий» — плейсхолдер «Расскажите, что понравилось или что стоит
  улучшить»
- кнопка отправки отзыва

**Вкладки «Мои» и «Обо мне»** — списки отзывов.

**Карточка отзыва:**

- аватар, имя, дата
- ряд звёзд
- текст отзыва
- маршрут поездки, если привязана

При пустом списке отзывов — блок с рейтингом: «Рейтинг X.X · N отзывов», подпись
«Рейтинг учитывает только опубликованные отзывы».

### 2.10 Уведомления — `/notifications`

- **Переключатель вкладок:** «Новые» · «Водитель» · «Пассажир».
- Кнопка «Прочитать все (N)» — с числом непрочитанных.

**Строка уведомления** (`Cell`, три строки):

1. событие — заголовок уведомления
2. «Имя · действие» — например «Анна • отправил заявку»
3. справа: шеврон перехода и время (`ЧЧ:ММ` сегодня, иначе дата и время)

- непрочитанные помечены точечным бейджем слева

### 2.11 Поддержка — `/profile/support`

Секции:

1. **«Обжалование блокировки»** — форма обращения (см. окно «Обращение в
   поддержку»). Показывается при блокировке аккаунта.
2. **«Частые вопросы»** — раскрывающийся список из 5 пар «вопрос / ответ»:
   - «Как забронировать место?»
   - «Как отменить бронь?»
   - «Как оставить отзыв?»
   - «Что делать, если водитель долго не подтверждает заявку?»
   - «Как работает подтверждение личности?»
3. **«Мои обращения»** — список обращений в поддержку. Карточка обращения:
   тема, дата, текст сообщения, при наличии ответа — блок «Есть ответ» с
   текстом ответа.

### 2.12 Жалобы — `/profile/reports`

**Секция «Мои жалобы»** — список строк `Cell`, по одной на жалобу:

1. «Категория · Тип» — например «Безопасность · Поездка»
2. начало описания жалобы
3. статус жалобы тоном: Ожидает рассмотрения / На рассмотрении / Закрыта /
   Отклонена
4. справа: шеврон перехода и дата подачи

Под списком — кнопка с иконкой флага **«Подать жалобу»**.

## 3. Всплывающие окна

Ниже — то, что окно показывает. Открывается окно из указанного места.

### 3.1 Автомобиль — из «Профиля» и с Главной

Заголовок: «Автомобиль».

- Подпись-пояснение: «Чтобы публиковать поездки, добавьте автомобиль.»
- Поля формы: «Модель» (плейсхолдер «Skoda Octavia»), «Цвет» (плейсхолдер
  «белый»), «Номер (необязательно)» (плейсхолдер «Например: 583»)
- Кнопка сохранения автомобиля
- Если автомобиль есть — кнопка «Удалить автомобиль» с подтверждением
  «Да, удалить» и пояснением: «Автомобиль будет удалён из профиля. Без него
  нельзя создавать новые поездки. При активных поездках удаление
  заблокировано.»

### 3.2 Редактировать профиль — из «Профиля»

Заголовок: «Редактировать профиль». Поля:

- «Имя»
- «О себе» — плейсхолдер «Например: за рулём 7 лет, люблю музыку 80-х»
- «Телефон» — плейсхолдер «+7 900 123-45-67»
  Кнопка сохранения.

### 3.3 Настройки — из «Профиля»

Заголовок: «Настройки».

- Карточка уведомлений с иконкой (колокольчик с бубенчиком — включены, без —
  выключены)
- Текст при включённых: «Уведомления включены — подтверждение брони, отмена и
  завершение поездки.»
- Текст при выключенных: «Некритичные уведомления выключены — критичные
  статусы поездки и брони останутся в приложении.»
- Кнопка «Выключить некритичные» / «Включить уведомления»
- Подпись: «Настройка синхронизируется с аккаунтом. Отдельные настройки звука и
  типов уведомлений пока не поддерживаются.»
- Кнопка «Открыть уведомления»

### 3.4 Заявки пассажиров — из карточки своей поездки

Заголовок: «Заявки пассажиров». Три группы строк:

1. **«Ожидают решения (N)»** — карточка: аватар, имя, «место N» и комментарий
   пассажира в кавычках, пилюля «Ожидает решения», две кнопки:
   - «Принять» с подтверждением «Подтвердить пассажира?»
   - «Отклонить» с подтверждением «Отклонить заявку?»
2. **«Подтверждены (N)»** — карточка: аватар, имя, «место N», пилюля
   «Подтверждён»
3. **«Закрытые (N)»** — карточка: аватар, имя, «место N», пилюля «Отклонён»
   либо «Отменён»

Внизу — кнопка «К моим поездкам».

### 3.5 Подать жалобу — из экрана «Жалобы»

Заголовок: «Подать жалобу». Поля:

- **«На что жалуетесь»** — выбор объекта из доступных: поездки (где вы
  пассажир), брони и люди, с которыми есть общая бронь. Подпись — тип,
  маршрут (или имя) и дата поездки. Список приходит с сервера
  (`GET /reports/targets`), вводить идентификатор вручную нельзя
- **«Причина»** — выбор категории: Безопасность / Мошенничество /
  Оскорбления / Спам / Недостоверная информация / Другое
- **«Описание»** — плейсхолдер «Опишите, что произошло», до 2000 символов,
  счётчик символов

В список попадают только объекты в окне жалобы: с начала поездки и до
7 дней после её окончания. Поездку, которая ещё не началась или кончилась
раньше, подать нельзя — её в списке нет.

### 3.6 Детали жалобы — по нажатию на строку жалобы

Заголовок: «Жалоба». Тело — колонка сверху вниз:

- шапка одной строкой: предмет «Категория · Тип» слева, статус пилюлей
  справа (тон по статусу, слова те же, что в ленте)
- дата подачи: «Подана 10.09.2026»
- полный текст жалобы (плашка-цитата)
- блок ответа — только у закрытых жалоб: подпись
  «Ответ модерации · 10.09.2026 · через 3 ч» (дата по Москве и сколько
  человек ждал), ниже — текст ответа, если модератор его оставил.
  Пока жалоба в работе, блока нет

### 3.7 Обращение в поддержку — из «Поддержки»

Заголовок: «Обращение в поддержку». Поля:

- **«Тема»** — плейсхолдер «Например: не приходит уведомление»
- **«Сообщение»** — плейсхолдер «Расскажите подробнее, что произошло»,
  до 2000 символов, счётчик символов

### 3.8 Новый запрос на попутку — с Главной и из «Истории запросов»

Заголовок: «Нужен попутчик». Поля:

- **«Откуда»** — подпись поля «Город отправления»
- **«Куда»** — подпись поля «Город назначения»
- **«Не раньше»** — время начала окна
- **«Не позже»** — время конца окна
- **«Места»** — число мест
  Кнопка «Опубликовать запрос». Подпись под формой: «Маршрут — водители увидят
  его в поиске».

## 5. Форматы отображения

Правила, по которым значения превращаются в текст на экране:

- **Даты и время поездок** — по московскому часовому поясу, независимо от
  часового пояса устройства.
- **Относительные подписи дат** — «Сегодня» / «Завтра» / «Вчера»; для дат
  другого года к подписи добавляется год.
- **Дата жалобы и обращения** — формат «09.09.2026».
- **Дата подачи заявки на попутку** — «30 сентября, 18:30».
- **Цена** — число и знак «₽».
- **Расстояние** — число и «км».
- **Длительность в пути** — «2 ч 30 мин», «45 мин».
- **Рейтинг** — одно знаковое число с одним десятичным знаком. Если отзывов
  нет, показывается прочерк «—», а не 0.0 и не 5.0.
- **Числа мест** — с правильным склонением: «место», «места», «мест».
- **Места** — от 1 до 3.

## 6. Библиотека компонентов

Экраны собираются из кита `@telegram-apps/telegram-ui`. Собственная обёртка
поверх кита:

| Компонент                 | Что это                                                                                                             |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `Page`                    | Корневой контейнер экрана: единые боковые отступы и вертикальный ритм                                               |
| `Section` + `SectionBody` | Секция экрана с заголовком                                                                                          |
| `Cell`                    | Строка списка: до трёх смысловых строк, правая колонка, аватар, шеврон, бейджи. Нажимаемая строка — нативная кнопка |
| `Card`                    | Блок с подложкой и скруглением                                                                                      |
| `Stack`                   | Вертикальный набор с интервалами                                                                                    |
| `Field`                   | Поле ввода: подпись, подсказка, ошибка, счётчик символов                                                            |
| `Button`                  | Кнопка: размеры `s`/`m`/`l`, иконка слева, состояние загрузки                                                       |
| `EmptyState`              | Заглушка: заголовок + описание + действие                                                                           |
| `Loading`                 | Спиннер или скелетон                                                                                                |
| `Notice`                  | Врезка: тон (warning / danger / info / success), текст                                                              |
| `Sheet`                   | Всплывающая шторка снизу                                                                                            |
| `Modal`                   | Всплывающее окно по центру                                                                                          |
| `Switcher`                | Переключатель вкладок сегментами                                                                                    |
| `Chip`                    | Небольшая метка-чип                                                                                                 |
| `IconButton`              | Круглая кнопка-иконка                                                                                               |
| `StatusPill`              | Пилюля статуса с тоном                                                                                              |
| `MenuRow`                 | Строка меню                                                                                                         |
| `SwitchRow`               | Строка с переключателем                                                                                             |
| `RatingPill`              | Пилюля рейтинга                                                                                                     |
| `CharCounter`             | Счётчик символов                                                                                                    |
| `FieldError`              | Текст ошибки поля                                                                                                   |
| `FetchMore`               | Конец ленты: кнопка догрузки                                                                                        |

Правила оформления, действующие везде:

- Три строки смысла у строки списка: заголовок, подпись, правая колонка.
- Кит сам рисует разделители между соседними строками списка.
- Интерактивные элементы — высотой не менее 44 px.
- Подпись-пояснение под переключателем: «Включена тёмная тема (как в
  Telegram)».
- Значимые слова пишутся текстом, цвет — только подсказка (правило работает и
  для статусов, и для бейджей).
- Шкала рейтинга отображается пятью звёздами.
